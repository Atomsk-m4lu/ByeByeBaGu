# 手机/电脑安装指南（手把手版）

`site/` 文件夹里就是你网站上需要的全部文件：

```
site/
├── index.html            ← 应用本体（八股闪背.html 的副本）
├── manifest.webmanifest  ← App 信息（图标、名称）
├── sw.js                 ← 离线缓存
├── icon.svg              ← 图标
└── 更新网站.bat          ← 以后改了功能，双击它同步最新版
```

下面任选**一条路线**走完即可。全程只需要做一次，之后 App 离线可用。

---

## 路线 A：GitHub Pages（推荐，免费且长期稳定）

全程在网页上点，**不需要装 git、不需要命令行**。

### 1. 注册/登录 GitHub

打开 https://github.com ，注册一个账号（已有就登录）。

### 2. 新建仓库

1. 点右上角 **＋ → New repository**
2. Repository name 填一个名字，比如 `shanbei`（下面会用到：`你的名字/shanbei`）
3. 选 **Public**（免费账户开 Pages 必须 Public）
4. 点 **Create repository**

### 3. 上传 site 里的 4 个文件

1. 仓库页面里点 **uploading an existing file**（或 Add file → Upload files）
2. 把 `site/` 文件夹里的 **index.html、manifest.webmanifest、sw.js、icon.svg** 四个文件拖进去
   （不要上传 更新网站.bat，那是本地用的）
3. 拉到最下面点 **Commit changes**

### 4. 开启 Pages

1. 仓库里点 **Settings → 左侧 Pages**
2. Branch 下面选 `main` 分支 + `/ (root)`，点 **Save**
3. 等一两分钟，刷新页面，顶部会出现网址：
   `https://你的用户名.github.io/shanbei/`
   用手机或电脑浏览器打开它，能看到应用就成功了。

### 5. 安装成 App

- **手机**：用 Chrome/Edge 打开网址 → 菜单（右上角三个点）→ **添加到主屏幕 / 安装应用** → 确认。桌面上出现绿色"背"字图标，打开是全屏，断网也能背。
- **电脑**：Chrome/Edge 打开网址 → 地址栏右侧出现**安装图标**（一个显示器加箭头的小图标）→ 点安装。之后在开始菜单/任务栏能找到它，是独立窗口。

### 6. 以后更新了功能怎么办

1. 双击 `site/更新网站.bat`（把最新代码同步进 index.html）
2. 用记事本打开 `site/sw.js`，把第一行 `'shanbei-v2'` 改成 `'shanbei-v2'`（版本号+1，强制所有设备更新缓存）
3. 回到 GitHub 仓库页面 → Add file → Upload files → 把这两个改过的文件重新上传覆盖 → Commit
4. 手机上的 App 下次打开会自动更新（或杀掉重开一次）

### 7. 换手机/多设备

进度存在各设备本地，不同步。迁移：旧设备 **设置 → 导出数据备份** 下载 JSON → 新设备 **设置 → 从备份恢复**。

## 路线 B：不想用 GitHub（Netlify Drop，拖一下就上线）

1. 打开 https://app.netlify.com/drop （需要免费注册/登录一次）
2. 把整个 `site/` 文件夹直接拖进网页
3. 几秒后得到一个 `https://xxxx.netlify.app` 网址，直接按路线 A 第 5 步安装

Cloudflare Pages、Vercel 同理，都是"选文件夹上传 → 得到网址"。免费额度对个人使用绰绰有余。

## 常见问题

- **必须一直联网吗？** 不。安装完成后完全离线可用；只有"第一次安装"和"以后更新版本"需要网络。
- **数据会上传到哪里吗？** 不会。复习记录、卡片全部存在设备浏览器的 localStorage 里，服务器上只有代码文件，没有任何你的数据。
- **本地双击 八股闪背.html 还能用吗？** 能，一直能用，和网站版是同一份代码。注意两边的进度是各自独立的（浏览器把 file:// 和 https:// 当成两个来源），选定一个当主力就好。
- **iOS 能装吗？** Safari 打开网址 → 分享按钮 → 添加到主屏幕。可以装，但 iOS 对 PWA 的离线和图标支持比 Android 弱一些，功能本身不受影响。
