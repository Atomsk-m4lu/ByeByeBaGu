# 不背八股 · 安装指南

三种用法，任选其一，都**完全免费、数据存在你自己设备上**：

| 路线 | 适合谁 | 耗时 |
|---|---|---|
| **A. 直接用在线版**（推荐） | 大多数用户：装上就能背 | 1 分钟 |
| **B. Fork 部署自己的站点** | 想自主可控 / 打算改代码的用户 | 3 分钟 |
| **C. 本地双击打开** | 只在电脑上用 / 不想碰 GitHub | 30 秒 |

---

## 路线 A：直接用在线版（推荐）

1. 手机或电脑浏览器打开：**https://atomsk-m4lu.github.io/ByeByeBaGu/**
2. 手机：浏览器菜单 →「添加到主屏幕 / 安装应用」→ 桌面出现图标，全屏、离线可用
   电脑：Chrome/Edge 地址栏右侧点「安装」→ 开始菜单出现独立窗口
3. 打开「导入」区拖入你的 md 文件，开始背诵

数据全部保存在设备本地浏览器中，与作者无关、不上传任何内容。
作者推送新版本后，App 打开时会自动检查更新（打开 → 划掉 → 再打开即生效）。

---

## 路线 B：Fork 部署自己的站点（进阶）

适合：不想依赖作者的在线地址、想要自己的域名、或打算修改代码。

1. 登录 GitHub，打开本项目：**https://github.com/Atomsk-m4lu/ByeByeBaGu**
2. 点右上角 **Fork** → Create fork（得到 `你的用户名/ByeByeBaGu`）
3. 在**你 fork 出来的仓库**里：Settings → Pages → Branch 选 `main` + `/ (root)` → Save
4. 一两分钟后，你的专属地址就是：
   `https://你的用户名.github.io/ByeByeBaGu/`
   打开它，按路线 A 的方式安装即可

**注意事项：**

- Fork 出来的仓库 **Pages 默认是关闭的**，第 3 步必须自己做
- Fork 会带走仓库的 README / LICENSE / 示例文件，属正常现象；如果你公开再分发，请保留 LICENSE 和 THIRD_PARTY_NOTICES.md（MIT 要求保留版权声明）
- 想同步作者的最新更新：你 fork 的仓库页面点 **Sync fork → Update branch**，Pages 会自动重新部署
- 想贡献代码：改完后走 Pull Request 回主仓库，欢迎

---

## 路线 C：本地双击打开（不部署）

1. 在仓库页面下载 `八股闪背.html`（点开文件 → 右上角下载按钮）
2. 双击用浏览器打开，拖入 md 文件即可

功能与在线版完全一致，只是没有图标和自动更新。适合不想把文件放到任何线上平台的情况。

---

## 常见问题

- **必须一直联网吗？** 不。A/B 安装完成后完全离线；C 本来就是本地文件。
- **多设备之间进度同步吗？** 不自动同步。各设备「设置 → 导出数据备份」下载 JSON，另一台设备「从备份恢复」。
- **清除浏览器数据会怎样？** 会连学习记录一起清掉（记录存在 localStorage）。更新版本永远不需要清数据；只勾「缓存的图片和文件」是安全的，「Cookie 及网站数据」是危险项。
- **iOS 能装吗？** 用 Safari 打开 → 分享按钮 → 添加到主屏幕。可以装，但 iOS 对 PWA 的离线支持略弱，功能本身不受影响。
- **更新后还是旧版？** App 打开 → 划掉后台 → 再打开（必要时两轮）；浏览器里是刷新两次。可到「设置」页底部看版本号确认。
