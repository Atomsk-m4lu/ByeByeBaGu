# PWA 部署说明（GitHub Pages，5 分钟）

目标：让不背八股变成手机/电脑上「可安装的 App」——有图标、全屏运行、完全离线，手机和电脑各自从浏览器安装。

## 一、准备文件

把以下 4 个文件放进你的 GitHub 仓库根目录（`deploy/` 目录里的三个文件复制出去，和 HTML 平级）：

```
你的仓库/
├── index.html            ← 把 八股闪背.html 复制一份改名为 index.html（保留原名也行）
├── manifest.webmanifest  ← 来自 deploy/
├── sw.js                 ← 来自 deploy/
└── icon.svg              ← 来自 deploy/
```

> `index.html` 是必须的：GitHub Pages 的站点根路径默认找它，PWA 的 start_url 也指向它。
> 以后改了功能，把最新的 八股闪背.html 重新复制覆盖 index.html 即可。

## 二、开启 GitHub Pages

1. 仓库推送到 GitHub 后，进 **Settings → Pages**
2. Source 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存
3. 等一两分钟，得到地址 `https://<你的用户名>.github.io/<仓库名>/`

## 三、安装到设备

- **手机（推荐 Chrome / Edge）**：浏览器打开上面的地址 → 菜单 → 「添加到主屏幕 / 安装应用」。得到独立图标，打开是全屏 App，完全离线可用。
- **电脑（Chrome / Edge）**：地址栏右侧会出现「安装」图标，点击后它变成一个独立窗口，出现在开始菜单和任务栏。

安装后第一次打开会缓存全部文件，之后断网也能背。

## 四、数据与多设备

- 数据存在**各设备的浏览器本地**（localStorage），互不同步。
- 换设备/换浏览器：旧设备「设置 → 导出数据备份」下载 JSON → 新设备「从备份恢复」。
- 清除浏览器数据会清掉卡片，重要进度请定期导出备份。

## 五、常见问题

- **为什么本地双击打开没有 PWA 效果？** Service Worker 只能在 HTTPS（或 localhost）下工作，这是浏览器安全要求。file:// 打开时应用会自动跳过注册，功能不受影响。
- **改了 index.html 但手机上还是旧版？** Service Worker 有缓存版本号：打开 `sw.js`，把第一行 `CACHE = 'shanbei-v2'` 改成 `'shanbei-v3'`（版本号 +1）推送即可强制更新。
- **iOS 支持吗？** 支持「添加到主屏幕」（Safari 菜单），但图标和离线体验比 Android/桌面 Chrome 略弱（iOS 对 PWA 的限制），功能本身不受影响。
