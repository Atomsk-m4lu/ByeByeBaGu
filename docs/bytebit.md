# ByteBit 吉祥物设计记录

> ByteBit（八比特）是本项目唯一的官方吉祥物：一只戴耳机写代码的 Q 版八哥。
> 原始设定、定稿过程与使用规范都在这份文档里，改形象前先读这里。

## 角色设定

- **物种**：八哥（myna），谐音"八股"；
- **性格**：聪明、机灵、爱吐槽的程序员鸟，常年戴耳机；
- **名字**：ByteBit = 字节 × 比特，也是"八比特"的音译，与"八股"呼应。

## 定稿设计（docs/bytebit.svg）

- **风格**：纯扁平矢量（SVG 手写，无渐变无阴影），禁止背景色块；
- **结构**：企鹅式坐姿单轮廓——浅灰头部圆（#3A414D）叠深色身体（#1B1F26），
  不露脚（坐在桌后的暗示）；无墨镜；
- **脸**：白色大眼 + 深色瞳孔 + 双高光点，象牙色两瓣弧线鸟喙（带鼻孔点）；
- **耳机**（照搬参考图结构，配色替换为品牌绿）：
  细头梁弧线（#00E676，宽 6）→ 顶部小垫块（#0A8F4D）→
  矩形耳罩 = 前板（#00E676）+ 深绿侧块（#0A8F4D）+ 黑色像素点（#0E1116）；
- **点缀**：荧光绿 #00E676 是唯一的强调色，只用于耳机和"思考/庆祝"像素火花；
- **配件**：白色咖啡杯 + 吸管 + 绿色像素 logo（仅限"场景类"使用，头像版不带）。

## 表情系统（三态）

| 状态 | 视觉 | 使用场景 |
|---|---|---|
| 正常 | 大眼平视 | 开屏、默认形象 |
| 思考 | 眼看斜上 + 挑眉 + 头顶绿色像素气泡 | AI 面试"思考中"、长加载 |
| 庆祝 | ^^ 眼 + 展翅 + 绿色火花 | 每日目标达成、总评好评 |

## 使用规范

- 头像/图标位：直接引用 `docs/bytebit.svg`（1:1，透明背景）；
- 应用内嵌：使用 HTML 内的 `<symbol>`（`bbSplashSym` 开屏含咖啡杯、
  `bbThinkSym` 思考态），改动形象时需同步；
- 小尺寸（≤44px）已验证可识别，再小不要用；
- 不要给 ByteBit 添加文字、墨镜或渐变材质（历史方案，已否决）。
