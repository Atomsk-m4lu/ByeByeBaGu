# Java 面试核心

## 第一章 JVM 基础

### 什么是 JVM？

JVM 是 Java 虚拟机，负责将字节码解释/编译为机器码执行。
其主要组成部分包括类加载器、运行时数据区和执行引擎。

### 运行时数据区包括哪些部分？

包括以下几块：

- 程序计数器
- 虚拟机栈
- 本地方法栈
- 堆
- 方法区

示例代码：

```java
// 这行注释里有 # 和 --- 都不应该被误切
public static void main(String[] args) { }
## 这行也不是标题
---
这行也不是分隔符
```
